# MaintainIQ - Asset Management System

## About The Project

MaintainIQ is an Asset Management web application created as part of an HTML, CSS, and JavaScript Hackathon.

The project is designed to help organizations manage assets and track their maintenance issues through a centralized system. It includes separate Admin and Technician experiences, asset management, issue tracking, asset details, public asset information, and interactive maintenance workflows.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- Font Awesome
- Phosphor Icons
- Google Fonts (Inter)

## Features

- Admin and Technician role-based login
- Admin dashboard for managing assets
- Technician dashboard for managing maintenance issues
- Add new assets with detailed information
- View asset details and maintenance history
- Edit existing asset information
- Retire assets with confirmation
- Generate and download asset QR codes
- Public asset details page
- Report maintenance issues for assets
- Maintenance issue management dashboard
- Issue statistics and status tracking
- Search and filter maintenance issues
- View detailed information about individual issues
- Start maintenance and resolve reported issues
- Reset application data to demo data
- Logout functionality
- Toast notifications for user feedback
- Responsive navigation with mobile menu
- Responsive design for mobile, tablet, and desktop
- Data persistence using Local Storage
- Dynamic UI updates using JavaScript and DOM manipulation
